PDF Table Extractor

Upload a PDF. Extract tables. Export to Excel.

面向海外用户的轻量级在线 PDF 表格提取工具：上传 PDF，识别并提取表格，预览检查后导出 Excel 或 CSV。

建议立项海外市场Next.js + TypeScriptVercel 部署

1. 项目概述

1.1 产品定位

用户上传 PDF 文件，系统自动识别其中的表格，转换为可编辑的 Excel 或 CSV 文件。

英文描述：Extract tables from PDF files and convert them into editable Excel or CSV spreadsheets in seconds.

1.2 目标用户

用户群体主要使用场景
会计、财务人员从财务报表、账单中提取数据
采购人员提取供应商报价单、采购清单
行政人员提取 PDF 报告中的表格
研究人员、学生提取论文、研究报告中的数据
小企业经营者从订单、价格表中提取数据
首批用户建议：小企业员工、会计人员、采购人员。优先选择 PDF 转 Excel 需求明确、处理频率较高的场景。

1.3 产品目标

  1. 上传 PDF。
  2. 自动检测 PDF 是否包含表格。
  3. 提取表格内容并展示预览。
  4. 选择需要的表格和页面。
  5. 编辑提取结果。
  6. 导出 Excel 和 CSV。
  7. 无需注册即可体验。

1.4 产品边界

第一版暂不做 PDF 编辑器、PDF 合并拆分工具集合、在线协作、账户与云端文件管理、批量处理、复杂文档问答和自动财务分析报告。

技术范围说明：数字 PDF 通常可以直接解析文字和位置；扫描版 PDF 需要 OCR，复杂表格还涉及版面识别。建议 V1 先做好数字 PDF，扫描件作为后续升级能力。

2. 核心功能需求

2.1 首页与文件上传 P0 必须开发

  • 支持拖拽上传 PDF，也支持点击按钮选择文件。
  • 显示文件名称和大小；支持删除、重新上传。
  • 校验文件类型；限制文件大小和页数。
  • 显示上传和处理进度。
  • 显示隐私说明。
项目初始限制建议
文件格式PDF
单文件大小20 MB
PDF 页数50 页
同时上传数量1 个
用户注册不需要

这些是产品初始限制建议，不代表 Vercel 平台硬性限制，后续应按解析性能和真实文件测试调整。

2.2 PDF 表格自动识别 P0 必须开发

上传后自动扫描文档，识别表格所在页码、行列数、内容、表头、空白单元格，以及数字、日期和文本。用户可选择全部表格、指定表格或指定页面。

识别结果示意页码行列状态
Table 1Page 212 × 4已识别
Table 2Page 418 × 6已识别
Table 3Page 78 × 3已识别

2.3 表格预览与编辑 P0 必须开发

  • 表格预览和单元格编辑。
  • 行列调整，删除空行、空列。
  • 修改列名、重新提取。
  • 显示原始页码。
  • 对数字识别不确定、表头缺失、内容错位或合并单元格不明确的情况显示警告。
无法确定的内容不允许系统默默修改，应显示警告并让用户检查确认。

2.4 Excel 和 CSV 导出 P0 必须开发

格式要求
XLSX每张表格可导出为独立 Sheet；保留列名、数据顺序，并尽可能保留数字格式。
CSV支持 UTF-8；正确处理逗号、引号和换行；防止 CSV Formula Injection。

2.5 隐私与文件安全 P0 必须开发

  • 不要求注册；不长期保存用户上传的 PDF。
  • 不保存提取出的表格内容；临时文件设置自动清理。
  • 不将 PDF 原文写入应用日志。
  • 上传接口进行文件类型和大小验证。
  • 传输过程使用 HTTPS。
  • 隐私政策说明文件是否会发送给第三方 OCR 或 AI 服务。
不长期保存不等于文件在处理期间绝对不会落盘。实际存储、清理和第三方处理流程必须与产品隐私声明一致。

4.3 处理流程

  1. 浏览器上传 PDF。
  2. 文件进入临时存储。
  3. 服务端读取 PDF。
  4. 解析文字及其坐标。
  5. 根据坐标、间距、边框等特征识别表格。
  6. 输出统一 JSON。
  7. 前端展示表格。
  8. 用户编辑并导出 Excel/CSV。
  9. 临时文件按设置清理。
Vercel 上传注意：普通 Vercel Function 请求体默认上限为 4.5 MB。建议采用浏览器直传 Vercel Blob 的方案，避免 PDF 文件经过 API 请求体转发。部署前应再次核对当前计划、Blob 上传方式和函数限制。

8. 验收标准

上线前至少准备 20 份真实 PDF 测试文件，覆盖简单网格表格、无边框表格、多页表格、多张表格、货币日期小数、空白单元格、加密 PDF 和扫描版 PDF。

  • 可以上传符合限制的 PDF。
  • 能正确显示 PDF 页数。
  • 能识别基本数字 PDF 表格。
  • 能显示表格页码、行数、列数。
  • 能选择指定表格。
  • 能编辑单元格。
  • Excel 导出数据与预览一致。
  • CSV 导出格式正确。
  • 异常文件有明确错误提示。
  • 临时文件能按规定清理。
  • 移动端可以正常上传和查看。
  • Vercel 正式环境部署成功。
首轮验收目标建议：20 份测试 PDF 中，至少 16 份能够正确提取预先选定的基础表格。该目标仅针对支持范围内的数字 PDF，不包含复杂扫描件。

9. 最终 MVP 范围

V1.0 必须完成

  • 数字 PDF 上传
  • 自动识别基本表格
  • 表格列表和页码
  • 预览与单元格编辑
  • Excel / CSV 导出
  • 基础错误处理
  • 隐私与服务条款
  • Vercel 部署

暂不开发

  • 扫描件 OCR
  • 批量 PDF
  • AI 数据分析
  • 用户历史文件
  • 订阅系统
  • 复杂表格结构恢复
  • 团队协作
  • 在线 PDF 编辑

产品核心

上传 PDF → 自动识别表格 → 预览编辑 → 导出 Excel / CSV。

第一版优先保证基础数字 PDF 的提取准确性和导出质量，再逐步增加 OCR、批量处理和付费能力。
